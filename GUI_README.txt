ЗАПИСЬ К ВРАЧУ — macOS, Apple Silicon (M1 и новее)

1. Дважды нажмите «Запись к врачу.app». Терминал не нужен.
   Светлая и тёмная темы следуют оформлению macOS, в том числе при его
   изменении во время работы приложения. Перезапуск для смены темы не нужен.
   Фон окна слегка прозрачен и размывает содержимое за ним средствами macOS.
   Текст, поля и карточки остаются чёткими. Системная настройка универсального
   доступа «Уменьшить прозрачность» может отключать этот эффект.
2. Заполните данные пациента, полное ФИО врача как на сайте и ссылку
   на список врачей gorzdrav.spb.ru. ID врача вводить не требуется.
   Кнопка «Импорт настроек…» переносит настройки из старого config.txt.
3. Выберите дату и время выдачи талонов (всегда московское время),
   длительность поиска и интервал проверок. Или включите «Начать поиск сейчас».
4. Выберите «Автоматическая запись» и нажмите «Начать запись».
   Режим «Проверка без создания записи» проходит только до сводки на сайте.

Приложение выбирает любой доступный талон к указанному врачу. Нажатие
«Начать запись» разрешает отправить заявку и принять необходимые для
записи условия сайта об обработке персональных данных.

Статус и подробности работы видны в окне. Браузер работает скрыто.
Поиск начинается за 15 секунд до указанного времени. При временных
ошибках сайта запросы повторяются с паузами; ограничения сервера учитываются.
При неопределённом результате отправленной заявки повторная отправка
блокируется: сначала проверьте запись на сайте самостоятельно.

На экране успешной записи отображаются дата, время, врач, специальность,
поликлиника, адрес и телефон, если сайт предоставил эти сведения.
Нажмите «Скачать PDF талона» и выберите папку. Если сайт не отдаёт PDF,
приложение предлагает явно обозначенную PDF-копию подтверждения.
Если сохранить файл не удалось, успешная запись остаётся действительной.

«Остановить» прекращает новые попытки. Если заявка уже отправлена,
приложение сначала ждёт её результат. Закрытие окна действует так же.
Временный сбой или ответ сайта могут задержать остановку до минуты.

Держите приложение открытым, компьютер включённым и подключённым
к интернету; крышку ноутбука не закрывайте. Во время работы приложение
предотвращает обычный сон от бездействия. Запуск однократный: автоматического
ежедневного повторения нет. Захват талона не гарантирован.

Python, Qt, Playwright и браузер находятся внутри .app. Файл config.txt
и папки с пакетами рядом не нужны. При первом поиске браузер распакуется
во временную папку. Для работы желательно иметь 1 ГБ свободного места.
Можно перенести .app в «Программы». Сборка предназначена для этого Mac
и не проходила нотариализацию Apple для распространения.

Поля формы не сохраняются автоматически. Результаты, PDF и журнал хранятся
локально в папке данных приложения (кнопка «Открыть результаты»):
~/Library/Application Support/Talon/Запись к врачу/
Эти файлы могут содержать персональные данные. Для повторного сохранения
талона после закрытия приложения используйте PDF из этой папки.
Существующие результаты прежней версии рядом с приложением или в соседней
папке release учитываются для защиты от повторной записи.

Старая версия release/Запись.command и её config.txt сохранены отдельно.

Для разработчика:
  .venv/bin/python -m pip install -r requirements-gui.txt
  .venv/bin/python build_gui.py
  .venv/bin/python -m unittest test_talon test_booking test_gui
Полная автономная проверка (без обращения к реальному сайту):
  .venv/bin/python talon_gui.py --self-test-report /tmp/talon-gui/report.json
